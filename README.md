# NutriVision_Project
A Computer Vision project for food recognition and nutritional information retrieval

- branch main: Biểu diễn ảnh, kênh màu hệ màu dữ liệu. Tiền xử lý (Các thao tác trên điểm ảnh; biến đổi hình học; lọc ảnh và khử nhiễu). Morphology, segmentation. HOG, Color histogram, phân loại SVM
- branch final_term: CNN (finetune EffnetB0), YOLO (World), SAM (Segment model), Pipeline ứng dụng ước lượng dinh dưỡng.
